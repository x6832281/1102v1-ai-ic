# 幻境回声 · EchoCraft V2.3 顶级艺术美化与视觉重塑设计方案

> **状态**：待用户审批 (Pending Approval)  
> **日期**：2026-11-18  
> **对标目标**：`chat.xstavern.com`（星宿酒馆）的高定艺术质感  
> **指导规范**：`frontend-design`（反模板化、反廉价感、高信息密度与呼吸感设计原则）

---

## 1. 背景与意图 (Intent and Why)

### 1.1 背景
本项目已在 R1~R28 轮次完成了“合规原创、卡源合一、世界书 v1、逐像素肖像软渲染器、130 项冒烟测试”等工程硬实力的筑基，项目运行稳定。然而从纯视觉艺术维度对标行业顶级标杆（`chat.xstavern.com`）时，当前页面依然呈现出偏向“轻量 Web 工具 / 扁平电商货架”的视觉惯性：
- 角色卡片画幅偏小（160px 方块），视觉分量轻，缺乏典藏立绘的仪式感。
- 材质层级扁平，缺乏高通透多层琉璃（Glassmorphism）、微内阴影与金属微光边缘。
- 对话界面偏向即时通讯（IM）左右气泡模式，缺乏视觉小说（Visual Novel）与沉浸电影舞台的深度与张力。

### 1.2 核心目标
站在顶级艺术总监与设计专家的视角，对全站外观进行一次彻底的脱胎换骨式重塑。让用户在打开网站的第一秒（The 1-Second Wow Effect）感受到如同踏入一间顶级奢华、静谧且带有未来科幻诗意的夜间私人沙龙。

## 2. 目标、非目标与反目标 (Goals, Non-Goals, Anti-Goals)

### 2.1 目标 (Goals)
1. **角色卡全面升级为 3:4 黄金比例典藏卡牌**：卡片宽度放大至 200px~240px，立绘高度与纵深大幅延展，配备多层发光外缘、悬浮微景深投影与精致身份铭牌。
2. **全局材质升级为 Glassmorphism 2.0（高透冷光琉璃）**：
   - 彻底告别单调灰黑底板，全站核心容器统一采用 `backdrop-filter: blur(24px)` 结合微弱内高光（`inset 0 1px 0 rgba(255,255,255,0.09)`）。
   - 边框采用细微双主色微渐变（萤青 + 琥珀拉丝微光）。
3. **对话空间升级为「沉浸式视觉小说剧场」（Visual Novel Theater）**：
   - 弱化生硬的聊天气泡框，引入半透明悬浮剧场对话面板。
   - 角色半身立绘与背景氛围光晕（`--scene-glow`）自然融入聊天舞台深处。
4. **字体与微排版净化（严格遵循 frontend-design）**：
   - 消除无意义的全大写英文 Eyebrow 标签、无意义的装饰连字符。
   - 强化中文字体字阶对比与行高韵律（字号梯度严谨、文本行长控制在 75 字符内）。
5. **多端平滑质感对齐**：移动端触控底栏与对话框同步继承高级琉璃质感，保证 360px~430px 小屏手机如同运行原生高定 App。
6. **零回归**：保持原有 130 项自动化冒烟测试全部通过，保证 `/?classic=1` 经典 SillyTavern 底层 100% 正常。

### 2.2 非目标 (Non-Goals)
- 本次升级专注于**界面外观、材质、动效与布局美学**，不涉及后端数据库改造、不新增商业登录账号系统。
- 维持当前 0 部署成本（Vercel Serverless + 纯前端软渲染）架构不变。

### 2.3 反目标 (Anti-Goals)
- **拒绝艳俗土豪金与跑马灯光污染**：绝不搞大面积刺眼金色或廉价晃动的 RGB 流光。金色仅作为拉丝高光与次级状态点缀，主基调必须深邃、克制、高贵。
- **拒绝千篇一律的 AI SaaS 卡片套件**：绝不使用千篇一律的软灰阴影（`rgba(0,0,0,0.1)`）或圆角粗框。
- **拒绝牺牲性能**：禁止引入任何体积巨大的 3D 库（如 Three.js）或庞大外部素材包，继续完全依靠现代化 CSS + 纯原生 Canvas 算法实现。

## 3. 方案权衡与已定路线 (Approaches)

在前期头脑风暴中，我们对比了三种设计路径：
1. **方案 A：星宿鎏金 · 奢华古典夜宴**（重度对标原站的威士忌琥珀金质感，沉稳奢华，但略偏厚重）。
2. **方案 B：幽夜星轨 · 极冷空灵琉璃**（主打深空黑与冷萤青，极致前卫，但亲和力偏冷）。
3. **方案 C：全景画报流 · 视觉小说剧场**（颠覆常规列表，彻底画报化，改动跨度过大）。

### 选定方案：方案 A 与方案 B 的「高定融合版」（星宿鎏金 × 幽夜星轨）
- **为什么选它**：融合了方案 A 的**材质深度与尊贵仪式感**（3:4 典藏卡、微琥珀金边缘拉丝）与方案 B 的**现代轻奢冷空灵**（纯净萤青冷光、高透磨砂冰琉璃）。既拥有对标站一目了然的高级感，又保留了 EchoCraft 独有的星轨与文学气质。

## 4. 详细视觉规范与设计令牌 (Design Tokens)

### 4.1 色彩体系 (Core Palette)
```css
:root {
    /* 核心底色：深渊黑曜石 (Void Obsidian) */
    --bg: #07090e;
    --bg-elevated: #0d1117;
    --bg-surface: #121822;

    /* 琉璃面板：多层高透磨砂 (Frosted Glass) */
    --panel-glass: rgba(14, 19, 28, 0.76);
    --panel-glass-deep: rgba(9, 13, 20, 0.88);
    --panel-border: rgba(255, 255, 255, 0.08);
    --panel-border-hover: rgba(0, 209, 178, 0.35);

    /* 双主色：萤青 (Cyan) + 琥珀 (Amber Gold) */
    --accent: #00d1b2;                   /* 主行动点 / CTA / 聚焦态 */
    --accent-glow: rgba(0, 209, 178, 0.18);
    --gold: #f59e0b;                     /* 荣誉高光 / 典藏标签 / 辅助高贵点缀 */
    --gold-glow: rgba(245, 158, 11, 0.22);
    --gold-border: rgba(245, 158, 11, 0.4);

    /* 文本层级 */
    --text-pure: #ffffff;                /* 标题与焦点高光 */
    --text-primary: #e6ebf2;             /* 正文标准色 */
    --text-secondary: #94a3b8;           /* 次要说明与副标题 */
    --text-muted: #5e6d82;               /* 注释、边角信息与冷提示 */

    /* 物理投影与环境光 */
    --shadow-card: 0 16px 36px -10px rgba(0, 0, 0, 0.65), 0 0 0 1px var(--panel-border);
    --shadow-card-hover: 0 24px 48px -12px rgba(0, 0, 0, 0.8), 0 0 24px var(--accent-glow);
    --glass-blur: blur(20px);
}
```

### 4.2 角色卡牌架构 (3:4 黄金比例典藏卡牌)
卡牌不再是贴片头像，而是完整的**立绘封印画境**：
```
+------------------------------------+
| [分类角标: 奇幻]      [♥ 典藏按钮] |
|                                    |
|             (立绘主景)             |
|       逐像素肖像软渲染 (240px)     |
|      环境粒子 / 细光 / 窗台        |
|                                    |
|------------------------------------|
| 角色姓名 (17px 纯白高光加粗)       |
| 身份定位 (12px 次级淡雅白)         |
| 设定摘要 (双行截断 / 行高 1.5)      |
| [♪ 专属音律]          [全 3 章]    |
+------------------------------------+
```
- **几何与排版契约 (Builder Decision)**：
  - **外容器与封面比例**：卡片封面图（`.card-cover`）规范为 `3:4` 高清画幅（占卡身约 62% 高度）；卡片整体外容器在桌面端为 `minmax(220px, 1fr)` 的黄金矩形（总高约 360px），在移动端平滑适配 `repeat(2, 1fr)`（总高约 270px），完美平衡立绘张力与滚动负荷。
  - **标签与元数据**：
    - `[全 3 章]` / `[独立档案]` 为静态章节容量元数据，读取 `char.script.chapters.length`，不改动存储结构。
    - `[♪ 专属音律]` 为展示性典藏属性标签，整卡点击统一唤起详情弹窗（`openDetail`），在弹窗内提供专门的播放/试听入口，杜绝外层冒泡冲突。
- **悬停动效**：轻盈抬升 `translateY(-6px)` + 边缘金色与青色微漫反射光晕扩散（`box-shadow` 柔和渐变）。

### 4.3 对话空间：沉浸式视觉小说剧场 (Visual Novel Theater)
```
+-------------------------------------------------------------+
| ◀ 返回档案   [角色头像] 白澈 · 守灯人 (第 2/3 章)  ✦ 🔊 ⤓ ⚙ |
+-------------------------------------------------------------+
|                                                             |
|                    (舞台深处环境母题光晕)                   |
|                   [当前场景专属柔和辉光]                    |
|                                                             |
|   [白澈]                                                    |
|   ┌─────────────────────────────────────────────────────┐   |
|   │ （擦拭着灯罩上的雨渍，眼底掠过一丝沉思）            │   |
|   │ 「雨港的雨下得越久，光芒就越难穿透雾气。你找到……」   │   |
|   └─────────────────────────────────────────────────────┘   |
|                                                             |
|                                               [我的发言]    |
|                                      ┌──────────────────┐   |
|                                      │ 我带来了第37盏灯 │   |
|                                      └──────────────────┘   |
|                                                             |
|   [▸ 询问灯塔历史]   [▸ 递上旧航海图]   [▸ 换个轻松话题]    |
|-------------------------------------------------------------|
| [ 输入对话内容...                                     ] 发送|
+-------------------------------------------------------------+
```
- **剧场化悬浮对话框与舞台架构 (Builder Decision)**：
  - **立绘与消息流的视觉关系**：采用“通透半隐消息流 + 舞台深层环境天光”的现代剧场架构。角色头像保留在顶栏与消息侧边；视窗深层通过 `--scene-glow` 动态投射分类专属柔焦光晕（深层 z-index: 0），长对话与移动端均能自然滚动，不遮挡文字阅读，完全兼容现有的 DOM 虚拟滚动与防卡顿机制。
  - **沉浸面板与分支选项契约**：保留 `#immersive-panel` 与顶栏 `✦` 切换按钮，确保 130 项冒烟测试 100% 通过。在视觉上，行动选项（`#chat-options`）重塑为悬浮在输入栏上方的通透琉璃胶囊芯片（Option Chips）；好感度与心境进度条作为精巧的 HUD 融入面板顶部。
  - **微表情与光晕表现**：文本层维持 `richText()` 的微动作斜体冷色与金色台词分色；肖像层通过心境（Mood）与好感度（Favor）动态施加头像微光外晕（如高好感施加金色柔光），不推翻静态缓存机制，保持极致流畅。
  - **头部功能键**：原有按键 ID 完全保留（保证事件绑定无误），视觉统一升级为 Glass 琉璃微按键。点击 ⚙ 平滑唤起设置，保持当前草稿不丢失。

## 6. 构建者交接与自由裁量区 (What's Left to the Builder)

以下工程细节留给构建者在实施时根据像素效果自由裁量微调：
1. **微动效曲线微调**：弹簧缓动贝塞尔曲线参数推荐 `cubic-bezier(0.16, 1, 0.3, 1)`，可针对移动端适当缩短 50ms。
2. **磨砂模糊降级适配**：在极少数低端或不支持 `backdrop-filter` 的旧机型上，自动安全降级为高不透明度深色底色（`#0d121a`）。
3. **冒烟测试守护**：修改后必须运行 `node tools/smoke.mjs`，确保全部 130 项断言 100% 保持全绿。
