2026.11.07 · PIXEL TAVERN

V1.3 「明炉真火」 上线版

炉膛里烧起了真的火——酒馆接入真实大模型，并为公网部署做好了全部准备：

  • 界面风格 — 全新「清晰」皮肤默认启用：系统字体、圆角卡片、柔和阴影、平滑过渡；复古像素风可在设置中随时切回，头像与炉火等像素画元素两种风格都保留。
  • 真实大模型对话 — 角色回复改由大模型流式生成：优先站点共享模型，也可在「设置 → 模型接入」填入你自己的 OpenAI 兼容接口（Key 仅存于本机）；未接入或连接失败时自动回退本地剧本引擎。
  • 连接测试 — 接入点支持一键「测试连接」，保存后立即对全站 21 位角色生效。
  • 全站访问计数 — 顶栏累计访问改为服务器端真实统计。
  • 上线就绪 — SEO 全套（OG/manifest/robots/sitemap/favicon）、Docker + Caddy 自动 HTTPS 部署套件、版权/隐私/年龄声明齐备，随时可用你自己的域名上线。
  • V1.2 回顾 — 轮换开场白、长图与多格式导出、历史统计、移动端抽屉、六模块架构与 41 项冒烟断言。

V1.2 「灯影渐浓」 持续打磨

两轮巡检与代码质量治理后，酒馆再次进化：

  • 轮换开场白 — 21 位角色全部拥有两段以上开场白，详情页「↻ 换开场」即点即换。
  • 长图与导出全面升级 — 对话可导出 纯文本 / Markdown / 分色长图（含预览弹窗与水印），单卡可导出 JSON 或标准 PNG 角色卡带走。
  • 多行输入 — Enter 发送、Shift+Enter 换行，输入框自适应增高。
  • 历史统计条 — 段数 / 消息数 / 互动角色 / 输出字数一目了然。
  • 移动端侧栏抽屉化 — ☰ 唤出滑入抽屉，遮罩点击关闭。
  • 代码质量 — 全站拆分为六模块分层架构，冒烟断言扩至 41 项。

V1.1 「炉火渐旺」 持续优化

定时巡检九轮迭代后，酒馆全面升级：

  • 像素字体本地化 — Zpix 子集化 4.68MB → 54KB，全站中文真像素渲染，CDN 完整版按需兜底。
  • 卡片全生命周期 — 自制卡可编辑（预填表单原地更新）、可删除；收藏角标实时同步。
  • 沉浸互动升级 — 剧情追踪像素时间线（当前章节 + 最近行动）、行动选项点击反馈态。
  • 数据安全网 — 本地数据一键导出/导入 JSON 备份，历史 30 段上限有提示。
  • 对话体验 — 消息名签与时间戳、气泡头像、回到底部、长对话自动折叠可展开、继续上次对话。
  • 氛围与性能 — 酒馆播报跑马灯、炉火呼吸光晕、页面切后台自动节能、窄屏全面适配。

V1.0 「炉火初燃」 上线

像素酒馆 Demo 正式点亮！本版本在原版 SillyTavern 之上改造出完整的像素酒馆门户：

酒馆须知

  • 角色回复由真实大模型生成：优先使用站点共享模型，也可在「设置 → 模型接入」配置自己的 OpenAI 兼容接口；未接入或连接失败时自动回退本地剧本引擎（离线可玩）。
  • 角色卡、收藏与聊天记录保存在浏览器本地，不会上传；可在「设置」中一键导出/导入 JSON 备份。
  • 「经典酒馆」即原版 SillyTavern 界面，集市中的角色卡 PNG 已自动放入其中，可直接使用原版全部功能。
  • 自制卡可随时在详情弹窗「✎ 编辑」修改或删除；超过 300 条的对话会自动折叠早期消息，可点击展开。
