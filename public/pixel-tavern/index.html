CHANGELOG更新通知

2026.11.05 · PIXEL TAVERN

V1.0 「炉火初燃」 上线

像素酒馆 Demo 正式点亮！本版本在原版 SillyTavern 之上改造出完整的像素酒馆门户：

  • 像素酒馆门户 — 公会柜台、角色书架、滑卡书架与角色卡集市全部上线，像素风 UI 全面重绘。
  • 内置对话引擎 — 每位角色内置专属剧本，无需 API Key 即可开聊；支持打字机效果与浏览器 TTS 朗读。
  • 沉浸互动 BETA — 完整剧情后给出三组行动选项、角色状态与剧情追踪，可随时切回传统聊天。
  • Build 角色卡制作 — 在浏览器里捏一个专属像素角色，立刻入书架、立刻开聊。
  • 像素点唱机 — 四首 8-bit 酒馆小曲由 WebAudio 实时合成，收起面板音乐不中断。
  • 经典酒馆直通 — 顶栏「经典酒馆」一键回到原版 SillyTavern 界面，角色卡已自动放入其中。

GUIDE使用指引

三步开始聊天

01挑选伙伴

在角色卡集市按分类或标签找到喜欢的角色卡。

02查看详情

点击封面查看角色信息与开场白，可先加入收藏。

03开始对话

进入对话页，输入消息即可；沉浸互动会给出行动选项。

酒馆须知

  • Demo 的角色回复由本地剧本引擎生成，离线可玩；接入真实大模型请使用顶栏「经典酒馆」进入原版 SillyTavern 配置 API。
  • 角色卡、收藏与聊天记录保存在浏览器本地，不会上传。
  • 「经典酒馆」即原版 SillyTavern 界面，集市中的角色卡 PNG 已自动放入其中，可直接使用原版全部功能。
