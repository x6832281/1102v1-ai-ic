# 幻境回声 · EchoCraft Studio

沉浸式原创角色叙事工坊与 AI 角色扮演沙龙（前端微光暗曜体系 + 本地剧本引擎 + 真实大语言模型流式交互）。

**当前版本 V2.0「星轨共鸣」**

- **线上正式站点（自定义域名）**：<https://ai-ic.top>（Vercel 零服务器托管：原创前端门户 + Serverless 接口，`git push` 自动触发全球边缘部署）

## 核心架构与原创特色

| 模块 | 说明 |
| --- | --- |
| 角色档案室 | 21 位深度原创角色档案，涵盖荒原深空、谧夜陪伴、思辨博弈、奇境异闻等主题；全套独立编写剧本 |
| 创作者工坊 | 在线起名、编写人设背景、挑选发色与氛围基调，程序化生成高质感肖像并即刻建立连线 |
| 沉浸互动分支 | 心境/共鸣状态双轨指示条、剧情时间线追踪、每轮决策行动选项，支持随时切回自由对话 |
| 环境音律舱 | 4 首平滑低噪环境氛围音景（WebAudio 实时合成，零音频外链，切后台不中断） |
| 共鸣波形仪 | Canvas 程序化流体正弦共鸣波形，高帧率平滑动画，支持减少动效偏好 |
| 双模兼容架构 | 优先使用真实大模型（站点共享模型 / 访客自带 API Key），未配置或离线时自动无缝回退本地剧本引擎 |
| 经典核心直通 | 顶栏一键直通原生底层 SillyTavern 完整引擎与高级扩展 |

## 快速本地启动

```bash
npm install        # 首次安装依赖
npm start          # 启动后自动打开 http://127.0.0.1:8000/
```

- **http://127.0.0.1:8000/** — 幻境回声门户（默认首页）
- **http://127.0.0.1:8000/?classic=1** — 经典底层核心（原版 SillyTavern 界面）
